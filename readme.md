## Overview

This repository contains my solutions for the TypeScript assignment. The assignment covers fundamental and intermediate TypeScript concepts, including:

- Functions with optional parameters
- Union types and type narrowing
- Readonly tuples
- Generics
- Interfaces
- Generic constraints with `keyof`
- Classes, inheritance, and access modifiers
- Asynchronous programming with `Promise`
- Type safety and best practices
