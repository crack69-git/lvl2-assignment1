# Generics

Generics allows us to create reusable components that work with different types while preserving type safety.Instead of writing separate functions for strings, numbers, or objects, we define a type parameter that acts as a placeholder for a type.

# Generics with Promise<T>

Generics allow TypeScript to know the exact type of data a Promise will return when it resolves. This provides type safety, autocompletion, and compile-time error checking.
